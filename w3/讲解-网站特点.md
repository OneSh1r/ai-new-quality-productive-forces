# 可视化 Pandas · 网站功能讲解

一份完整的说明：这个网站是什么、每个标签页能做什么、怎么用最快。

---

## 一、它是什么

**把 pandas 的日常分析搬到图形界面上。** 你用鼠标做的每一次筛选、排序、分组、透视、连接、画图，
右侧都会同步生成**等价的、可以直接运行的 pandas 代码**；反过来，代码页里的每一行也都能点回界面看结果。

三条设计原则：

1. **能画图就不摆数字**——分布、关系、缺失、离群值、多维取舍优先用图形表达，点一下图形就是一次筛选。
2. **一个概念串起全站**——所有功能都围绕「当前列」组织，任何地方点一个列名，它就能被送到任何工具。
3. **对初学者友好**——默认只露出 8 个最常用的操作，每个都配一句人话说明；其余能力收在一处「显示全部」，不挡路。

中英双语、深浅两套主题、纯前端实现：双击 `index.html` 即可使用。

## 二、打开与运行

* 直接双击 `index.html`（推荐 Chrome / Edge）：**不需要安装、不需要构建、完全离线**。
  所有脚本、样式与图形库（d3 7.9、p5 1.9）都放在 `assets/` 里，不连任何 CDN。
* 可选：用任意静态服务器打开，这样「从网址加载数据」也能用。

```bash
python -m http.server 8000     # 然后访问 http://localhost:8000
```

## 四、数据加载：六种来源

1. **默认数据**：打开即用内置的「全球零售订单」——2,614 行 × 16 列，含时间、地区、渠道、品类、折扣、利润，
   并且故意留了缺失值与重复行，方便练习清洗。
2. **示例数据集**：鸢尾花测量、城市空气质量（含传感器中断造成的空白区段）、乘客名单（大量缺失值）、
   区域负责人（一张用来做连接的维表）。菜单里只列出**还没加载过**的示例，不会重复添加。
3. **上传文件**：CSV / TSV / TXT / JSON / JSONL / XLSX，也可以直接把文件拖到页面上（页面会给出放置提示）。
   * 文本文件会先弹出**解析对话框**：分隔符（自动识别）、首行是否为列名、是否推断类型、缺失值标记，并实时预览前几行。
   * XLSX 由内置的 ZIP + deflate 读取器解析，不依赖任何外部库。
4. **粘贴数据**：从 Excel 或网页复制一块表格直接粘进来。
5. **从网址加载**：抓取远程 CSV / JSON（`file://` 下浏览器可能拦截跨域请求，用静态服务器打开即可）。
6. **生成随机数据**：指定行数、列数、随机种子、缺失比例与数据模式（随机 / 时间趋势 / 分群 / 相关变量），
   同一个种子每次生成的结果完全一致。

## 六、覆盖的 pandas 能力：24 个可视化操作

左栏操作面板里的每一个操作，都会同时给出等价的 pandas 代码。默认露出 8 个常用操作，
点「显示全部操作」可以看到全部 24 个，也可以直接搜索「filter」「groupby」快速定位。

| 分类 | 可视化操作 | 等价 pandas |
| --- | --- | --- |
| 行 | 条件筛选（可视化条件 / 文本表达式，支持 `&`、`\|`、between、isin、isna） | `df[df["a"] > 1]` |
| 行 | 排序（多列、升降序） | `df.sort_values([...], ascending=[...])` |
| 行 | 采样（head / tail / sample，随机抽样可复现） | `df.head(n)`、`df.sample(n, random_state=42)` |
| 行 | 去重（可指定子集与保留策略） | `df.drop_duplicates(subset=[...], keep=...)` |
| 行 | 缺失值处理（删除 / 填常量·均值·中位数·众数·前后值） | `df.dropna()`、`df.fillna(df["c"].mean())`、`ffill` / `bfill` |
| 列 | 选择列 | `df[["a", "b"]]` |
| 列 | 删除列 | `df.drop(columns=[...])` |
| 列 | 重命名列 | `df.rename(columns={...})` |
| 列 | 类型转换（int / float / str / category / datetime / bool） | `df["c"].astype("int64")` |
| 列 | 新增列（表达式） | `df["m"] = df["profit"] / df["revenue"]` |
| 列 | 分箱（等宽 / 等频） | `pd.cut(...)` / `pd.qcut(...)` |
| 列 | 字符串处理（大小写、包含、提取、切分、替换…） | `.str.upper()`、`.str.contains()`、`.str.extract()` |
| 列 | 日期特征（年 / 月 / 日 / 星期 / 季度 / 期间…） | `.dt.year`、`.dt.weekday`、`.dt.to_period("M")` |
| 列 | 值映射 | `.replace({...})` |
| 列 | 排名（平均 / 最小 / 最大 / 首次出现） | `.rank()` |
| 列 | 数值变换（裁剪 / 取整 / 差分 / 环比） | `.clip()`、`.round()`、`.diff()`、`.pct_change()` |
| 列 | 独热编码 | `pd.get_dummies(df, columns=[...])` |
| 聚合 | 分组聚合（求和 / 均值 / 中位数 / 最小 / 最大 / 计数） | `df.groupby([...], as_index=False).agg(...)` |
| 聚合 | 透视表（支持总计与小计、填充值） | `df.pivot_table(index=..., columns=..., values=..., aggfunc=..., margins=True)` |
| 聚合 | 交叉表（含卡方检验的 p 值） | `pd.crosstab(...)` |
| 聚合 | 滚动窗口（可设窗口与最小观测数） | `df["c"].rolling(window=7, min_periods=1).mean()` |
| 聚合 | 时间重采样（日 / 周 / 月 / 季 / 年） | `df.set_index("t").resample("D").agg(...)` |
| 多表 | 表连接（左 / 右 / 内 / 外，可带 `_merge` 标记与列名后缀） | `df.merge(other, how=..., left_on=..., right_on=..., indicator=True)` |
| 多表 | 追加行 | `pd.concat([df, other], ignore_index=True)` |

每一步加入流水线后：数据表、图表、数据概览、代码页会**同时更新**，右侧流水线记录这一步的行数变化
（例如 `2,614 → 804`）与耗时；每一步都可以停用、编辑参数、调整顺序、单独查看代码或删除。

统计口径与 pandas / numpy 对齐：样本标准差（`ddof=1`）、线性插值分位数、无偏偏度与峰度、
IQR 离群值、Pearson / Spearman / Kendall 相关系数、卡方检验 p 值。

## 七、核心机制：当前列（全站联动）

点任意一个列名（表头、左栏列列表、数据概览的表格、图表里的取值），它就成为「当前列」，
顶栏出现一个芯片：`当前列 revenue float64 ×`。点这个芯片（或检查器里的「用这一列…」）会展开同一个菜单：

| 菜单项 | 效果 |
| --- | --- |
| 看分布（直方图） | 打开图表页并画好直方图 |
| 看取值（值计数） | 打开数据概览，用这一列做值计数 |
| 作为图表 X / Y 轴 | 直接改写图表设置并切到图表页 |
| 按它分组汇总 | 打开汇总页，分组键就是这一列，统计列自动选好 |
| 用它筛选 | 打开筛选面板并预填这一列 |
| 查看统计 | 检查器显示它的完整统计 |
| 作为连接键 | 打开合并页，左右键都预填好 |

因为所有面板都以同一个「当前列」为准，所以在数据概览里点一个列图谱缩略图，
数值分布、相关性矩阵、散点矩阵与检查器会**一起跟着变**。

## 九、数据概览

一屏把一张表讲清楚，从上到下：

* **关键指标**：行数、列数、缺失单元格、完全重复行，配环形进度与构成条。
* **列图谱**：每个列一张缩略图（分布 / 频数 / 时间曲线）+ 类型 + 缺失率，**点一下即设为当前列**。
* **缺失矩阵**：每一行是一条记录，标出空值出现的位置——成块的空白说明缺失是成片出现的，而不是零散的。
* **关联矩阵**：数值×数值用 Pearson、类别×类别用 Cramér's V、混合用相关比 η，一张图看全部变量关系；
  点数值格子可以直接生成散点图或密度图。
* **缺失值分布**：每列的缺失比例；点一下条形即可打开「缺失值处理」并预填这一列，底部还有一键「处理缺失值」。
* **数据质量检查**：常量列、高基数列、缺失偏多、完全重复行、离群值，并给出一键处理入口。
* **值计数**：所选列的取值频数横向柱状图，**点柱子即筛选该取值**。
* **数值分布 / 相关性矩阵 / 散点矩阵**：单变量分布、两两相关、两两对照。
* **`df.info()` 与 `df.describe()`**：与 pandas 一致的两张表。

## 十一、汇总：分组聚合 / 透视表 / 交叉表

「汇总」页把三个构造器放在一起，用顶部标签切换：

* **分组聚合**：选分组列与统计列（求和 / 均值 / 中位数 / 最小 / 最大 / 计数），可指定输出列名；
  右侧实时给出预览表格与预览图表。
* **透视表**：指定行、列、值、聚合方式（另有唯一数与标准差），支持总计与小计（margins）与填充值。
* **交叉表**：行 × 列的频数表，可选择是否显示边际合计，并给出卡方检验的 p 值。

预览图表本身就是可点的：点一根柱子就相当于「按这个类别筛选原始数据」（下钻），
确认无误后点「加入流水线」，这一步就会进入结果与代码。

## 十五、撤销与重做

右栏「流水线」标题右侧就是**撤销 / 重做**按钮：

* 按钮带文字，鼠标悬停写明将撤销的动作，例如 `撤销 · 排序 · Ctrl/⌘+Z`；
* 面板里有一行「上一步操作：分组聚合」，随时知道当前处在哪一步；
* 可**连续撤销 / 重做任意多步**（最多 60 步），每撤销一步重做按钮立刻可用；
* 撤销的粒度是「一次操作」：加一步、删一步、改参数、停用、移动顺序、清空流水线、
  添加或删除数据集都各算一步——**删除数据集也能撤销**（数据仍在内存里，撤销即恢复）；
* 撤销记录会在「重置工作台」与「载入会话」时清空，避免误回到上一个工作状态。

## 十七、动效

两套视觉层叠加在自研的 SVG 图表引擎之上，都**可选**：库缺失、或系统开启「减少动态效果」时
自动退化为静态渲染，功能不受影响。

| 图层 | 用途 |
| --- | --- |
| **d3 7.9** | 图表重绘时的图形过渡（按 `data-key` 匹配旧位置，柱 / 点 / 折线平滑移动）、关键指标数字滚动、新图形错峰淡入 |

## 十八、规模与边界

* 全部计算在浏览器内完成，面向**百万行以内**的数据。
* 图表默认最多绘制 **4,000** 个点；超过 **1,200** 个点的散点改用单条路径渲染，
  悬停与点击由均匀网格最近邻索引接管，交互保持不变。
* `file://` 下「从网址加载」会受浏览器跨域策略限制，用静态服务器打开即可。
* 解析 XLSX 只读取单元格的文本与数值，不处理公式与样式。
* 单步流水线最多回退 60 步；会话保存的表超过 6 万行时会截断。

```bash
node tests/run-all.js
```

## English summary

**Visual Pandas** is a browser data-analysis workbench: every mouse action — filter, sort, group,
pivot, join, chart — is translated into equivalent, runnable pandas code, and the generated code is
verified cell-by-cell against real pandas.

* **Graphical first** — column atlas, missing matrix, association matrix, 2-D density and parallel
  coordinates; clicking any mark filters the data.
* **One linkage model** — a "current column" follows you across the table, profile, charts,
  summarisers and the join builder.
* **Beginner friendly** — eight common operations and six common chart types up front, everything
  else one click away.
* **Bilingual and offline** — Chinese / English dictionaries are key-identical, and the whole app
  runs from a single `index.html` with no network.
* **Multi-table** — several datasets at once, each with its own pipeline, plus join, append, and a
  60-step undo history that also covers dataset add / remove.
* **Verified** — 1,222 automated checks across nine suites, including two end-to-end suites in a
  real browser.
