> 配套文件：`deepseek_html_20261007_9a8ea9 (1).html`（单文件页面）、`lib/d3.min.js`、`lib/p5.min.js`、`images/p1–p9`
> 打开方式：直接双击 HTML 文件，全部资源本地加载，**无需联网、无需构建**

## 一、项目概述

这是一个围绕"人工智能是新质生产力的核心引擎"这一主线做的**单页多级可视化网站**：用一条主标题 + 五个二级界面，把"概念定义 → 政策脉络 → 产业承载与标杆 → 数据佐证 → 总结"讲成一条完整叙事，并全程用动效与可视化强化"AI 驱动生产力跃升"的主题。

- 页面规模：主页面 + 5 个二级界面、8 个行业标杆案例、6 个政策节点、6 张数据图表、11 屏滚轮播放内容
- 技术栈：原生 HTML / CSS / JavaScript + **D3 v7**（数据可视化）+ **p5 v1.9**（Canvas 动效）
- 体积：HTML 约 166 KB，D3 约 273 KB，p5 约 1 010 KB，全部本地化
- 兼容：现代浏览器直接运行；D3 / p5 缺失时自动降级为纯 CSS 版本，不会白屏或报错

## 三、八个关键亮点

### 亮点 1｜主标题右侧的二级菜单 + 滑动指示器

- 菜单位于标题"人工智能 ——新质生产力的核心"**右侧、同一高度**，底色为纯灰（#d9d9d9），与浅色页面形成克制对比。
- 激活态由一枚**渐变胶囊指示器**承担，切换页面时胶囊在标签间平滑滑动并自动伸缩宽度（0.45 s 弹性缓动）；用 `MutationObserver` 监听标签状态，首次加载、点击、窗口缩放都会重新对位。
- 五个二级界面**互斥显示**（未停留的整页 `display:none`），点击菜单即跳转并自动滚到该页顶部；标签支持键盘聚焦与回车触发。

### 亮点 2｜01 / 05 页：滚轮逐屏播放 + 弹幕式汇聚

- 页面被拆成**固定高度的舞台**（6 屏 / 5 屏），鼠标滚轮在舞台范围内一次翻一屏（0.46 s 节流，防抖防连翻）；滚到首屏 / 末屏后再滚动会**放行页面滚动**，不会把用户"锁死"。
- 每屏关键信息按 **"左 → 下 → 右 → 上"四个方向依次飞入**：标签从左、标题从下、导语从右、要点交替飞入、结语从上落下，形成弹幕汇聚的观感。
- 与此同时，p5 画布会从四条边抛出粒子，**汇聚到对应标题 / 要点的位置**后淡出，让"信息从四方涌来"的效果有粒子层面的呼应。
- 左侧三级菜单**默认收起**，只露一个显示当前屏号的窄把手（01–06），鼠标悬停或键盘聚焦时向右展开完整步骤列表，点击任一步骤直达对应屏。

### 亮点 3｜02 页：横向政策时间轴（D3 绘制）

- 六个政策节点（2025.03 政府工作报告 → 2026.01 "人工智能+制造"专项行动）沿**一条横轴上下交替**排布，卡片内是日期、标题与三行摘要，避免长文堆叠。
- 轴、节点圆、连接线全部由 **D3 + SVG** 绘制：渐变轴条、随窗口尺寸实时重算的节点坐标、以及一颗沿轴往返流动的"**政策脉冲**"光点，表达"政策链条两年内迅速闭合"。
- 悬停 / 聚焦某张卡片时，对应节点用 180 ms 过渡放大并填充品牌紫；点击可固定弹出完整详情（政策原文要点、标签、三阶段目标等）。
- 进入该页时，六张卡片沿轴两侧**错峰入场**（每张 90 ms 间隔、560 ms 缓出），并有兜底定时器确保最终一定可见。

### 亮点 4｜03 页：产业分类 ⇄ 行业标杆 双向联动

- 左侧是三个产业分类方块（战略性新兴产业 / 未来产业 / 传统产业数字化升级），点击展开该产业的关键信息，再次点击折叠，**同一时间只展开一个**。
- 右侧把 8 个行业标杆融合成**一条可拖拽的无限循环轨道**：卡面在首尾各复制一份，拖到端点时瞬时错位回中间份，因此可以一直向左或向右循环拖动；圆点指示器按可见卡面数量重建。
- 每张卡**左上角标注所属产业分类**（带对应色点），人一眼就能看出这张标杆属于哪个产业。
- **双向联动**：拖动或停留在某张卡面时，左侧自动展开它所属的产业分类并更新标题与数量；反之点击左侧分类时，右侧平滑滑到该分类的第一张标杆卡（在循环轨道的中间份定位，保证两侧仍可继续循环）。

### 亮点 5｜04 页：全球 / 全国尺度的数据看板

- 顶部 **4 个 KPI 数字滚动**：15.7 万亿美元（2030 年 AI 对全球 GDP 的增量贡献）、80%（该增量占 GDP 增量比重）、42%（中国数字经济占 GDP 比重）、72%（全球大型企业 AI 采用率）。
- **6 张 D3 图表**，覆盖不同分析视角：
  1. **六维雷达**：效率提升、质量提升、创新加速、成本优化、要素激活、产业带动（5 分制）；
  2. **双序列趋势**：中国 AI 核心产业 vs 全球 AI 市场，2020 = 100 指数化到 2025；
  3. **行业渗透率**：12 个行业的 AI 应用渗透率（互联网与软件 78% → 建筑 25%），按区间分色；
  4. **企业采用率**：大 / 中 / 小型企业 2023 → 2025 的分组柱状对比；
  5. **气泡图**：横轴渗透率、纵轴投入增速、气泡大小代表市场规模；
  6. **三要素环形图**：AI 对劳动资料 / 劳动者 / 劳动对象的贡献占比。
- 每张图都有**入场动画**（雷达面淡入、折线描边生长、条形依次长出、柱体升起、气泡回弹）与**悬浮数值提示**（如"互联网与软件：AI 渗透率 78%""中国 AI 核心产业 2025：指数 322"）。
- 数据来源在页脚统一说明"公开资料整理，部分为趋势示意，不作为精确统计口径"，避免把示意值当作精确统计。

### 亮点 6｜统一而有层次的动效体系（p5）

- **页面底层粒子网络**：缓慢漂移的节点与连线铺在内容之下，鼠标移动时会出现柔和光晕，指针附近的连线与节点被提亮，像"数据被聚拢"。
- **看板数据流**：面板背后有四条缓慢横向流动的渐变光带，光带上跑着数据包小光点，营造"数据在流动"的氛围。
- **粒子迸发**：悬停图表元素时从指针位置迸出小簇粒子，KPI 数字落定时各迸发一次（带节流与数量上限，避免堆积）。
- **卡片柔光 + 3D 倾斜**：数据面板、标杆卡、产业方块、时间轴卡片在鼠标进入时生成随指针移动的紫色柔光，并做最大 4°–5° 的透视倾斜，移出平滑回正。
- **细节反馈**：菜单标签、步骤按钮、产业分类标题点击处扩散涟漪；二级页面切换采用"淡入 + 轻微缩放 + 模糊消散"的过渡。

### 亮点 7｜工程健壮性与可访问性

- **离线可用**：D3、p5 均放在本地 `lib/` 目录，不依赖 CDN；把 HTML 单独拷走也不会报错。
- **优雅降级**：D3 或 p5 未加载时，时间轴回退到纯 CSS 轴与节点、看板不绘制图表但其余内容与交互照常可用。
- **动画兜底**：所有依赖动画的元素都配有定时兜底（如时间轴卡片、图表数值、漏斗条形），即使动画被中断也不会出现"内容永远看不见"。
- **隐藏页保护**：宽度为 0 的隐藏二级界面不绘制图表与轨道，切换进来时重新测量并重绘，避免错位。
- **可访问性**：交互元素使用语义化 `button`、`aria-label`、`aria-expanded`；步骤菜单支持 Tab 聚焦与方向键翻屏；`prefers-reduced-motion` 环境下自动关闭粒子、倾斜与涟漪。
- **响应式**：断点 1200 / 1000 / 900 / 820 / 700 px，分别切换看板列数、产业两栏堆叠、时间轴转纵向、菜单紧凑排列。

### 亮点 8｜内容与数据的可维护性

- 所有图表数据集中为脚本顶部的数组，改数即改图：`radarData`、`penetration`、`adoptData`、`bubbleData`、`trendSeries`、`donutData`。
- 文案与卡片结构保持语义化 HTML，便于直接替换文字或增删卡片；行业标杆卡只需维护 `data-group` 与左上角分类标签即可自动进入联动逻辑。
- 视觉规范集中：统一的主色（#2e7d9e 深海蓝、#7c3aed 紫）、圆角（16–22 px）、阴影与缓动曲线（cubic-bezier(0.22,1,0.36,1)），便于整体换肤。

## 四、技术实现一览

| 模块 | 关键技术 | 说明 |
| --- | --- | --- |
| 页面框架 | 原生 HTML / CSS（Grid + Flex） | 单文件、零构建、零依赖安装 |

| 数据看板 | **D3 v7**（`pie` / `arc` / `axis` / `scalePoint` / `curveMonotoneX` / `d3.timer`） | 6 图 + KPI 数字滚动 |
| 动效层 | **p5 v1.9 实例模式**（Canvas 2D） | 背景粒子网络、看板数据流、粒子迸发 |
| 悬浮提示 | 原生 DOM + D3 事件 | 统一深色气泡、自动避让窗口边缘 |

## 五、使用与二次开发

1. **直接使用**：双击 `deepseek_html_20261007_9a8ea9 (1).html` 即可；如需分享，请连同 `lib/` 与 `images/` 目录一起拷贝。
2. **改数据**：在页面脚本中搜索 `radarData` / `penetration` / `adoptData` / `bubbleData` / `trendSeries` / `donutData`，替换数组数值即可，图表会自动重绘。
3. **改文案**：直接编辑 HTML 中对应卡片文本；行业标杆卡新增一条时，复制一个 `.single-card-item`，设置 `data-group` 并在 `.bench-cat` 中写分类名即可自动加入循环轨道与联动。
4. **调节特效强度**：背景粒子数量见 `(s.width * s.height) / 90000`；看板数据流数量见 `const n = 4`；粒子迸发上限见 `if (parts.length > 120)`；时间轴脉冲时长见 `duration(5200)`。
5. **关闭某类特效**：删除对应的 p5 `new p5(...)` 代码块即可（页面其余部分不受影响）；全局关闭动效可依赖系统的"减少动态效果"设置。
